Set up Spotamp

Spotamp plays through your own Spotify app. This takes about two minutes, once. Spotify Premium is required.

  1. 1

    Create a Spotify app

    ✓

    In the Spotify Developer Dashboard, create an app with any name. Under Redirect URIs add the address below, and tick Web API.

    http://127.0.0.1:5174/callback
  2. 2

    Paste the app's Client ID

    ✓
  3. 3

    Sign in to Spotify

    ✓

    Lets Spotamp read your playlists and control playback.

  4. 4

    Connect the player

    ✓

    Spotamp plays sound as its own Spotify Connect device, “Spotamp”. It asks Spotify to sign in once more, for that device.
